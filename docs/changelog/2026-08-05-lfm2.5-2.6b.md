# 2026-08-05 - LFM 2.5 2.6B Integration

**What**: LFM 2.5 2.6B was incorporated into the Windows environment with `text` and `agentic` profiles, launchers, pinned artifacts, and documentation. The official checkpoint declares `max_position_embeddings = 131072`, but the installed GGUF retains `lfm2.context_length = 128000`. Both launchers apply an explicit override of that key so the runtime does not reduce the slot.

**Where**: `models\lfm2.5-2.6b`, `config\models\lfm2.5-2.6b.psd1`, `config\catalog.psd1`, `scripts\models\lfm2.5-2.6b`, `README.md`, and `docs\overview\models`.

**Why**: LFM 2.5 2.6B is a dense reasoning model from Liquid AI with a 131,072-token context window. The Q8_0 quantization was chosen to minimize quantization loss for reasoning and tool use, as it fits in the RTX 5080's 16 GB VRAM.

**Validation**: SHA-256 passed two independent checks. Both profiles generated valid argument plans. The `text` and `agentic` profiles responded with `n_ctx_slot = 131072`. The model uses eight threads, Q8 KV cache, Flash Attention, and a single slot. No MTP or vision is installed.
