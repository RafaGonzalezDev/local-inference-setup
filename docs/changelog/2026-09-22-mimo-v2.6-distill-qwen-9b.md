## 2026-09-22 — MiMo V2.6 Distill Qwen 9B Q6_K

**What**: Register pinned Q6_K weights and the F16 vision projector, with four
self-contained agentic profiles: text and vision, each at 131k and 262k context.
Add optional llama.cpp b10964 installation alongside the unchanged b10502 default.

**Where**: `config/catalog.psd1`, `config/models/mimo-v2.6-distill-qwen-9b.psd1`,
`scripts/models/mimo-v2.6-distill-qwen-9b/`, `scripts/setup/Install-LlamaRuntime.ps1`,
`README.md`, and `docs/overview/models/mimo-v2.6-distill-qwen-9b.md`.

**Why**: Reuse the existing verified-download and launcher-validation workflow
without changing existing model profiles. Retain the embedded MiMo template and avoid unsupported MoE/MTP options.
The initial loopback-only binding was subsequently corrected to `0.0.0.0`
for WSL access, matching Ornith 1.5 9B; no firewall rules were added.

**Validation**: Both artifacts passed size/SHA-256 checks; all four profiles
passed declarative validation. Text and vision short smoke tests passed at
262k and released port 8080. Those smoke tests preceded the binding correction;
131k inference and WSL end-to-end access were not verified by them. See the
[model card](../overview/models/mimo-v2.6-distill-qwen-9b.md) for limitations.
