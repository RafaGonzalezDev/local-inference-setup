# 2026-08-07 - LFM 2.5 8B A1B Integration

**What**: LFM 2.5 8B A1B was incorporated into the Windows environment with `text` and `agentic` profiles, launchers, pinned artifacts, and documentation. The official model declares 8.3 billion total parameters, 1.5 billion active, and a 128,000-token context window. It is a reasoning checkpoint without vision.

**Where**: `models\lfm2.5-8b-a1b`, `config\models\lfm2.5-8b-a1b.psd1`, `config\catalog.psd1`, `scripts\models\lfm2.5-8b-a1b`, `README.md`, and `docs\overview\models`.

**Why**: LFM 2.5 8B A1B is a reasoning model from Liquid AI with a 128,000-token context window. The official Q8_0 quantization was chosen to minimize quantization loss for reasoning and tool use, as it fits in the RTX 5080's 16 GB VRAM.

**Validation**: SHA-256 passed two independent checks. Both profiles generated valid argument plans. The `text` and `agentic` profiles responded with `n_ctx_slot = 128000`. The model uses eight threads, Q8 KV cache, Flash Attention, and a single slot. No MTP or vision is installed.
