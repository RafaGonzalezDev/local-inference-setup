# 2026-09-23 - Ornith 1.5 9B Q4_K_M evaluation (reverted)

**What**: Evaluated switching Ornith 1.5 9B from `Ornith-1.5-9B-AD-IQ4_XS.gguf`
(`AtomicChat/Ornith-1.5-9B-GGUF`) to the upstream `Ornith-1.5-9B-Q4_K_M.gguf`
(`ornith-ai/Ornith-1.5-9B-GGUF`). The switch was reverted the same day: the
reference configuration was expected to be a larger quantization, so the
`AD-IQ4_XS` artifact stays active. No quality or performance comparison between
the two builds was measured, so this entry makes no such claim.

**Where**: `config/models/ornith-1.5-9b.psd1`,
`scripts/models/ornith-1.5-9b/start-agentic-262k-1024.cmd`,
`models/ornith-1.5-9b/SHA256SUMS` and `docs/overview/models/ornith-1.5-9b.md`

count in its validation section is 26, not the previously documented 21.

**Why**: Test whether the official `Q4_K_M` build could replace the third-party
derivative. It does not, because the intended baseline is a higher-bit
quantization. Context, batching, sampling, cache, runtime and alias were never
modified, so the revert is limited to the artifact reference.
