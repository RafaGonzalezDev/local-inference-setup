# 2026-08-19 - Update llama.cpp runtime to b10502

## 2026-08-19 - Pin the Windows CUDA runtime to b10502

**What**: Update the official Windows x64 CUDA 13.3 runtime from `b10361`
(`14e78ddef`) to `b10502` (`0adcc3bb5`). The installer verifies both release
archives by SHA-256 and accepts the current semantic `--version` format while
still requiring the pinned build and commit. All 15 existing launchers now
reference `b10502-cuda13.3`; no launcher was added, removed, or otherwise
reconfigured.

**Where**: `scripts/setup/Install-LlamaRuntime.ps1`, every existing
`scripts/models/**/start-*.cmd`, `runtimes/llama.cpp/b10502-cuda13.3/`,
`packages/llama.cpp/b10502/`, `docs/overview/inference-backend.md`, and the
Nemotron model card.

**Why**: Keep the native Windows inference runtime current while preserving
the versioned deployment layout and the installed `b10361-cuda13.3` runtime as
a rollback option.

- `llama-server.exe --version` reported

- A static audit reviewed all 15 existing launchers: each has exactly one
  `SERVER` assignment, references `b10502-cuda13.3`, and resolves to an

- The global configuration command still expects 17 launchers while the
